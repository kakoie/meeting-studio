# 회의록 스튜디오 (PWA)

Lovable 없이 자체 호스팅할 수 있는 정적 웹 앱 프로젝트입니다.

## 기능
- PC/모바일 반응형 화면
- HTTPS에서 브라우저 마이크 오디오 녹음
- 지원 브라우저의 한국어 음성 인식(Web Speech API)
- 오디오 파일 및 TXT 내보내기
- 키워드 기반 회의 요약 초안
- 브라우저 로컬 저장, PWA manifest 및 서비스 워커

## 한계
- AI 서버 전사/AI 요약은 포함하지 않습니다.
- 자동 음성 인식은 브라우저·OS마다 지원이 다릅니다. 지원되지 않는 모바일 브라우저에서는 녹음 파일은 저장할 수 있어도 텍스트를 직접 입력해야 할 수 있습니다.
- 브라우저 음성 인식은 브라우저 공급자의 서비스로 음성이 처리될 수 있습니다.
- 회의 기록은 현재 브라우저에 저장되며 다른 기기와 동기화되지 않습니다.
- `file://`로 직접 열지 말고 HTTPS 주소로 배포해 마이크 권한을 테스트하세요.

## 무료 호스팅 예시: GitHub Pages
1. GitHub에서 새 저장소를 만듭니다.
2. ZIP 압축을 풀고 `index.html`, `manifest.webmanifest`, `sw.js`를 저장소 최상위에 올립니다.
3. 저장소의 Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
4. 제공되는 `https://계정명.github.io/저장소명/` 주소를 휴대폰에서 엽니다.
5. 마이크 권한을 허용하고 녹음 시작/종료/오디오 저장을 테스트합니다.

이 ZIP은 소스 프로젝트입니다. 공개 URL은 호스팅 계정에서 배포 설정을 완료해야 생성됩니다. 여기서 계정 로그인이나 배포를 대신 완료한 것은 아닙니다.


## 음성 인식 언어
앱에서 한국어, 영어(미국/영국), 일본어, 중국어(표준어), 스페인어, 프랑스어, 독일어를 선택할 수 있습니다. 실제 지원 여부는 브라우저와 운영체제에 따라 다릅니다.
